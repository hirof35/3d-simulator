# 3D 立体図形シミュレーター (3D Geometric Shape Simulator)

Node.js (Vite) と Three.js をベースに構築された、ブラウザ上で動作するインタラクティブな3D立体図形シミュレーターです。
立方体、球体、円錐、角錐などの様々な3Dオブジェクトを直感的に配置・変形・管理することができます。

## 🚀 主な機能

- **リアルタイム3Dレンダリング**: 影や質感を表現する `MeshStandardMaterial` を使用した美しいグラフィック。
- **ターンテーブル（自動回転）**: 空間上のオブジェクトがゆっくりと自動回転し、立体感を視覚的にわかりやすく展示。
- **ギミック操作 (TransformControls)**: モデリングソフト（BlenderやUnity等）のように、矢印やリングをドラッグして直感的に「移動」「回転」「拡大縮小」が可能。
- **精密キーボード回転**: 選択した図形を矢印キーで15度ずつ正確に回転。
- **オブジェクトの複製（クローン）**: 選択した図形と同じ形状・色・大きさをその場に即座に複製追加。
- **動的カウンター**: 画面内に存在している立体図形の総数をリアルタイムに計測して描画。
- **完全メモリ管理**: オブジェクト削除時にジオメトリやマテリアルをGPUメモリから解放（`dispose`）し、ブラウザの負荷を軽減。

## 🛠️ 開発環境 / 使用技術

- **Runtime**: Node.js
- **Build Tool / Dev Server**: Vite
- **3D Engine**: Three.js (WebGL)
- **Language**: JavaScript (ES6+ HTML5/CSS3)
